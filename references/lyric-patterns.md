# Lyric Patterns

Reusable lyric structures for the musical mnemonic technique.  
Fill the slots with any domain’s content.

## Pattern: Chorus Mapping (core pairs)
Best for high-frequency items you want to drill.  
Repeat the mapping several times in the chorus.

```
[Chorus]
[Concept A] means [Explanation A]
[Concept A] means [Explanation A]
[Concept B] means [Explanation B]
[Concept B] means [Explanation B]
[Concept C] means [Explanation C]
[Concept C] means [Explanation C]
```

## Pattern: Question–Answer Dialogue
Best for conversational or sequential material.  
Use with male/female or two-voice styles.

```
[Verse]
[Voice 1]
[Question or prompt]
[Voice 2]
[Answer or response]
[Voice 1]
[Next prompt]
[Voice 2]
[Next response]
```

## Pattern: Spaced-Repetition Chorus
Same mapping chorus returns multiple times, with new material in the verses.

```
[Verse 1]
... new items ...

[Chorus]
... core mappings ...

[Verse 2]
... new items ...

[Chorus]
... core mappings ...

[Bridge]
... additional items ...

[Final Chorus]
... core mappings ...
```

## Pattern: Concept → Example
Useful for programming, chess tactics, rules, etc.

```
[Verse]
[Concept name]
[Short definition]
[Concrete example]
[Why it matters]
```
